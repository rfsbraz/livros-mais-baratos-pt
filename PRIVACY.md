# Privacy

By default, the extension reads the current page only after the user opens it. If the user enables automatic alerts and grants site access, it also detects book pages while browsing selected, authorized shops. Page HTML is processed locally to find an ISBN, title and current price; HTML is not uploaded. On manual or automatic comparison, the ISBN and, when needed, the book title are sent directly to the selected, authorized bookshops. They receive normal connection information, including IP address, and apply their own privacy policies. Requests omit session cookies. Only selected automatic stores are requested as optional host permissions; manual links open ordinary store pages using normal browser privacy settings.

Saved titles, ISBNs and observed prices remain in `chrome.storage.local`, not Chrome sync. At most 100 saved books, 200 ISBN histories and 360 observations per ISBN are retained. On updating a book's history, observations older than 90 days for that book are removed. Old histories for unqueried books can remain until replaced by the 200-book bound or deleted.

Automatic results are cached only in the hidden extension document's memory, with at most 50 ISBN/store-selection entries and a ten-minute reuse window. They are not written to price history. Disabling alerts or changing authorized shops closes that document, cancels its requests and clears its cache. Dismissals last for the current page document. There is no scheduled monitoring of saved books, browsing-history collection, analytics, advertising, affiliate tracking, remote code or account system.

Selected store IDs and the automatic-alert preference are saved locally. **Desativar avisos automáticos** stops automatic checks and removes notices from open pages. Use **Apagar dados** to delete the shelf and history, reset store selection and disable automatic alerts. Uninstalling removes extension storage. Optional site permissions can be revoked in Chrome's extension settings.
